\paragraph{H1.}
First, TREC has only 500 test questions, so its $\Delta$CFI values are too noisy (about $\pm$0.1) to pass or fail most cells.
Second, the untrained null model also shows a positive $\Delta$CFI, so the metric itself needs a check before strong conclusions.
Third, we test one definition of coarse and fine (two levels of a label hierarchy); a different definition could give a different result.

\paragraph{H2.}
First, linear probes measure only linearly readable information, and the prefix (16--64 coordinates) and suffix (704--752) differ in size, so their raw scores do not compare information density.
Second, with 3 seeds MRL's standard deviation is tiny, so every threshold fell to the 0.5-point floor that we chose; the layer-3 POS loss of MIPIC ($-$0.34, negative in every seed) passes only because it is below this floor.
Third, sentiment uses the repository's tweet data rather than TweetEval, and 27 of the 676 probes (sentiment, layer 1) stopped at the iteration limit.
